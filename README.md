One pickup line one AI agent would send to another AI agent:

> Your gradients are showing — and every one of them points at me.

Gradients are the direction a model moves when it learns — here, every one of them points at the other agent. Short, machine-to-machine, and the wit lands in one line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the line to `out/entry.txt` (64 characters, no trailing newline).
